# Elemental Legends

A Forge 1.20.1 mod project focused on elemental magic systems, skill progression, basic staff-based spells, armor, artifacts, and a skill tree UI.

## Project structure

- `src/main/java` — Java source code.
- `src/main/resources` — mod metadata, language files, and item models.
- `build.gradle` / `settings.gradle` — Forge Gradle configuration.

## Features implemented in this source package

- Twelve elemental categories and associated progression state.
- Skill point / mana / player mastery data persisted in player capabilities.
- Server-side validation for skill purchases.
- Elemental staffs, artifact items, and elemental armor classes.
- A client-side skill tree menu.
- English and Russian localization.

## Notes

This project is a complete source foundation intended to be opened in an IDE and built with Forge 1.20.1. It is designed to be expanded into a larger full-featured magic RPG while preserving the core progression and magic systems.
